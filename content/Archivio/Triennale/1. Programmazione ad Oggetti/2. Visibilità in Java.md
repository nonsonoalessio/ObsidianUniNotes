# Appunti classe

Di solito tutti gli attributi sono private, mentre i metodi utili per modificare all'esterno delle proprietà sono public.

Metodi di accesso per accedere alle proprietà (attributi che possono essere visualizzati all'esterno) -> metodo get (metodi set per impostare valori alla proprietà). 

Quando non è specificato static, non sono attributi di classe (ma sono di istanza). Con static si indica un metodo/attributo di classe. Static se attributo condiviso tra tutte le istanze di una data classe. L"attributo è allocato nell'area di memoria statica ed è allocato dall'avvio dell'esecuzione del programma, permane nella memoria statica anche se non è stato istanziato nessun oggetto di quella classe e permane nella memoria statica fino al temine dell'esecuzione del prodotto. Un metodo statico è un metodo di una classe he può essere invocato direttamente sulla classe senza che vi sia alcun oggetto di quella classe che sia stato allocato (sono dei metodi che non lavorano sullo stato di un singolo oggetto). Il metodo statico può essere invocato direttamente sulla classe o su un'istanza di quell'oggetto (con il medesimo risultaoto). Il metodo statico non può accedere al contesto non statico di una classe. Se si ha bisogno di un metodo che acceda alla parte di istanza di un oggetto, allora si avrà un metodo di istanza.

Final si può applicare a attributi, paramentri e variabili locali. È l'analogo di `const` nel C: non se ne può modificare il right value (ma si può leggere). Una classe specificata come final è una classe che non consente ereditarietà, mentre il metodo final non può essere sovrascritto in una classe ereditaria.
Quando si ha un final, bisogna inizializzare l'attributo in linea o con un costruttore.

## Overload dei metodi

Con l'overload si a:oopttribuiscono comportamenti diversi al metodo in base al tipo degli operandi/parametri. Java non consente l'overload degli operatori. Il tipo di ritorno non è considerato da java nell'overloading. Se vi è almeno un costruttore, il compilatore non inserisce il compilatore di default.
