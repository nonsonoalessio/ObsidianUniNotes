# Appunti classe

Relazione "has a" (composizione) and "is a" (ereditarietà).

Protected: visibile a tutte le classi del package + altre classi di altri package che la estendono/.

Se attributo private, in una classe figlia non può accedere agli attributi del padre se non con i metodi. Questo server per garantire manutenibilità e riutilizzailità.

***

Classe astratta: se almeno un metodo ha senso come interfaccia ma, per il livello di astrazione, non è possibile implementarlo. Usa la keyword `abstract`. Se almeno un metodo è astratto, anche la classe sarà astratta. Non si può istanziare un oggetto di una classe astratta.

Interface: classe **completamente** astratta, solo metodi astratti (nulla di implementato). Non c'è stato (== attributi). Una classe può contenere più interfacce.
