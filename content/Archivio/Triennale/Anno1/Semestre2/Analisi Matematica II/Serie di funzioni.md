# Serie di funzioni
## Definzione
Data $\{f_k\}_{k \in \mathbb{N}}$ una successione di funzioni, con $f_k: \mathbb{I} \subseteq \mathbb{R} \rightarrow \mathbb{R}$, si definisca la ***successione delle somme parziali***:
$$s_1 = f_1$$ 
$$s_2 = f_1 + f_2$$
$$s_k = f_1 + f_2 + ... + f_k$$
La successione $\{S_k\}_{k \in \mathbb{N}}$ è la serie di funzioni:
$$\sum^{+ \infty}_{k = 1} f_k = f_1 + f_2 + ... + f_k + ...$$
>[!tip] Serie di funzioni e serie numeriche
>Fissato $x \in \mathbb{I}$, $\displaystyle \sum^{+ \infty}_{k=1} f_k (x)$ diventa una serie numerica.
