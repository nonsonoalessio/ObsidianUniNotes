# Teorema di Cauchy-Hadamard
**Anche:** *della radice*.

## Enunciato
Sia $\displaystyle \sum^{+ \infty}_{k=0} a_k x^k$ una serie di potenze. Se esiste:
$$\lim_{k \rightarrow +\infty} \sqrt[k]{|a_k|} = l$$
allora:
$$
\rho =
\begin{cases}
\displaystyle \frac{1}{l}, \ 0 < l < +\infty
\\
+ \infty, \ l = 0
\\
0, \ l = +\infty
\end{cases}
$$
